Get Started in Under 30 Seconds

No npm, no composer, no database configuration setups required.

# 1. Download single file litesql.php into your web root
curl -O https://raw.githubusercontent.com/litesql-studio/litesql-studio/main/litesql.php
# 2. Run PHP built-in web server locally
php -S localhost:8000
# 3. Open browser & login with default password
URL: http://localhost:8000/litesql.php | Default Password: admin
# 4. Framework Integration (Laravel / Symfony / WordPress)

If your database file is outside the public folder (e.g. Laravel's database/database.sqlite), keep it 100% safe from browser downloads by placing litesql.php in public/ and updating Line 19:

$scanDirectory = dirname(__DIR__); // Scans parent directory & database/ folder

Production Security & Hardening

Follow these essential security steps to protect your database server.

1. Change Master Password

Log in ➔ Click 🔒 Security in top header ➔ Enter current password (admin) and set a strong new password. Automatically hashed via PHP BCrypt.

2. Delete After Maintenance

If used for temporary database tasks on a live server, delete litesql.php immediately after use. Simply re-upload when needed in the future!

3. Restrict Access by IP

Add IP restriction rules in your .htaccess to restrict access exclusively to your trusted IP address.

4. Enforce HTTPS / SSL

Always serve LiteSQL Studio over encrypted HTTPS connections to prevent credential sniffing on public networks.
